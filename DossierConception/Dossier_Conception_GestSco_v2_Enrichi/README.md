# Dossier de Conception Technique - Progiciel GestSco v2.0

## 📋 Description

Ce dossier contient la documentation complète de conception technique du Progiciel de Gestion Intégré (PGI) **GestSco**, conforme au référentiel du CAMES pour les établissements d'enseignement supérieur au Burkina Faso et dans l'espace francophone africain.

## 🛠️ Technologies

**Frontend** : Angular 12, TypeScript, Bootstrap 5
**Backend** : Java 17, Spring Boot 2.7, JHipster 7.9, Hibernate
**Base de Données** : PostgreSQL
**Build** : Maven
